# baibian-app

AI image generation app built with Expo and React Native.

## Tech Stack

- Expo SDK 56
- React Native 0.85.3
- React 19.2.3
- Expo Router (file-based routing)
- TypeScript

## Getting Started

```bash
npm install
npx expo start
```

## Scripts

- `npm start` — Start Expo dev server
- `npm run android` — Start for Android
- `npm run ios` — Start for iOS
- `npm run web` — Start for web
- `npm test` — Run tests

## Project Structure

```
baibian-app/
  app/            # Expo Router pages
  components/     # Reusable components
  assets/         # Images, fonts
  __tests__/      # Test files
```
